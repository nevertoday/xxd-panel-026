XXD Panel 026은 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 사진 속 피사체, 외곽선, 자세, 구조 축, 거리, 서사적 관계를 읽고, 그 근거를 미니멀한 기하, 가는 선, 부드러운 색채군, 살짝 도드라진 종이 부조로 옮깁니다.

사진 위에 저채도 필터를 씌우는 작업이 아닙니다. 왜 이 사진이 주목받을 가치가 있는지를 보존합니다.

## 왜 만들었나요

많은 ‘사진을 미니멀 포스터로’ 만드는 워크플로는 같은 원, 파스텔 색면, 건축적 선으로 끝납니다. 결과는 차분해 보이지만 원본과 거의 관계가 없습니다. 몸짓은 사라지고, 관계는 템플릿으로 대체되며, 제목은 전혀 다른 이미지에도 그대로 붙일 수 있습니다.

026은 고요함을 근거에 기반한 디자인으로 다룹니다.

- 원본 고유의 정체성 단서를 최소 세 가지 남깁니다.
- 기하, 외곽선, 구조, 음형으로 피사체를 지우지 않고 다시 조직합니다.
- 고정 팔레트가 아니라 원본에서 저자극 색 역할 4–6가지를 번역합니다.
- 깊이는 눌리거나 살짝 도드라진 종이 정도로 제한하며 노골적인 3D를 쓰지 않습니다.
- 생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력을 선택합니다. 자동 문구는 원본에 단단히 묶인 제목과 마이크로카피를 만듭니다.

## 사진의 사실에서 휴머니즘 기하로

내부 방법은 다음과 같습니다.

**관찰 → 식별 → 단순화 → 인간화 → 부조 → 조판 → 검수**

피사체는 유일한 시각 중심으로 남습니다. 구성은 중앙으로 모이되 딱딱한 대칭이 되지 않습니다. 양형과 음형, 조절된 밀도, 작은 어긋남, 넉넉한 고요한 공간이 리듬을 만듭니다. 형태는 인터페이스 속 카드처럼 떠 있는 대신 고운 종이에서 살짝 눌러 만든 듯해야 합니다.

색은 아이보리, 웜 화이트, 옅은 회색, 모래색, 더스티 핑크, 옅은 황토, 안개 낀 파랑, 세이지 쪽으로 이동할 수 있습니다. 이는 프리셋이 아니라 방향입니다. 주조색, 보조색, 구조색은 반드시 현재 사진의 빛, 재료, 분위기로 설명할 수 있어야 합니다.

## 네 가지 출력, 하나의 휴머니즘 기하

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| 상하 | 원본 적응형 | 위에는 원본 사진, 아래에는 휴머니즘 기하. 각 패널이 원본의 전체 크기를 유지하며 높이가 정확히 같습니다. |
| 좌우 | 원본 적응형 | 왼쪽에는 원본 사진, 오른쪽에는 휴머니즘 기하. 각 패널이 원본의 전체 크기를 유지하며 너비가 정확히 같습니다. |
| 디자인 단독 | 원본 적응형 | 원본은 근거로만 쓰이고 최종 캔버스에는 나타나지 않습니다. 원본 비율과 크기를 유지합니다. |
| 배경화면 세트 | 기기별 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치용 PNG 네 개를 각각 출력합니다. |

사용자가 지정한 정확한 픽셀값이 가장 우선합니다. 지정하지 않은 일반 모드는 고정 비율을 강요하지 않고 원본에 맞춥니다. 상하 모드는 사용자가 지정한 전체 높이가 짝수여야 하고, 좌우 모드는 전체 너비가 짝수여야 합니다. 정확한 요청 크기를 몰래 바꾸지 않습니다.

배경화면 세트에도 몰래 적용되는 기본 크기는 없습니다. 일반 기기 프리셋인 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`를 선택하거나 기기명을 붙인 사용자 지정 해상도를 입력합니다.

배경화면 세트는 두 가지 관계를 지원합니다.

- **연결형 세트:** 먼저 기준 작품 하나를 승인합니다. 나머지 세 기기에는 원본 사진과 승인된 동일 기준 작품을 함께 참조로 주고 각 기기에 맞게 새로 구성합니다.
- **독립 작품 네 장:** 각 기기는 원본 사진만 참조하며 더 자유로운 구성을 탐색할 수 있습니다.

연결형은 크롭을 뜻하지 않습니다. 네 배경화면 모두 독립적으로 생성하고 구성하며 검수합니다.

## 문구는 나중에 붙이는 라벨이 아닙니다

생성 전에 026은 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 묻습니다. 자동 문구는 주 제목 하나와 마이크로카피 2–4개 그룹을 사용합니다. 눈에 보이는 사실, 관계의 긴장, 근거 있는 함의에서 문구를 추출하고 ‘무관한 이미지 교체 테스트’로 검증합니다.

사용자 지정 문구 모드에서는 정확한 주 제목과 선택적 마이크로카피를 입력할 수 있으며 완성 문구는 그대로 유지합니다. 방향이나 수정 가능한 초안은 허용된 범위 안에서만 다듬습니다. 무문자 모드는 모든 글자를 제거합니다.

문구 언어는 외모에 대한 추측이 아니라 의도한 독자를 따릅니다.

**목표 시장 또는 독자 지역 > 지정한 출력 언어 > 지시문 언어; 모두 불분명하면 생성 전에 질문**

일본어판은 자연스러운 일본어를, 한국어판은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 자연스러운 현대 표준 아랍어, 올바른 글자 결합, 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 모든 지역판은 직역하거나 가짜 외국어 문자로 꾸미지 않고 해당 언어답게 재창작합니다.

## 시작하기

```bash
git clone https://github.com/nevertoday/xxd-panel-026.git
mkdir -p ~/.codex/skills
ln -s "$(pwd)/xxd-panel-026" ~/.codex/skills/xxd-panel-026
```

Claude Code 사용자는 같은 폴더를 `~/.claude/skills/xxd-panel-026`에 연결할 수 있습니다. 설치 후 에이전트 세션을 다시 시작하세요.

```text
$xxd-panel-026
이 사진을 상하 구성으로 만들어 주세요. 주 제목은 일본어로 써 주세요.
```

사진만 첨부해 호출해도 됩니다. 번호가 붙은 여러 줄 메뉴로 출력 모드를 먼저 묻고, 배경화면의 관계를 지정하지 않았다면 연결형과 독립형 중 하나를 다시 묻습니다.

## 경계와 신뢰

- 현재 사진만 현재 작업의 콘텐츠 원본으로 사용하며 다른 입력, 과거 결과, 예시 피사체를 빌리지 않습니다.
- 원본과 매개변수가 같아도 호출할 때마다 새 작업 폴더를 만듭니다.
- 짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 범위의 환경 확장만 적용해 사진성을 지킵니다.
- 디자인 단독 및 배경화면 모드에는 원본이 나타나지 않으며 SVG, HTML, 프로그램 드로잉을 비트맵 생성의 대체물로 쓰지 않습니다.
- 래스터 생성 가능 여부는 특정 환경 변수 하나의 부재가 아니라 실제 기능으로 판단합니다.
- 안전한 비트맵 브리지는 정제된 상태만 반환하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 서버 응답 본문을 노출하지 않습니다.
- 일반 모드는 원본마다 파일 한 개, 배경화면 모드는 콜라주 미리보기가 아닌 정확히 네 개의 독립 파일을 반환합니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 래스터 경로가 필요합니다.
